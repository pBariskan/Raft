What it is

One algorithm, three ways to run it

The core

Leader election, log replication, the commit rule and persistence, written against Figure 2 of the Raft paper. The core never touches a clock, a socket or a file, so it runs identically everywhere. No Raft library was used.

The simulator

Virtual time, a network that delays, loses and splits messages, and servers that crash and reboot from their simulated disks. Seeded, so every run can be replayed exactly. It powers the tests, the chaos runner and this site.

Real servers

The same core behind a 10 ms clock, a checksummed write-ahead log with fsync, and HTTP between processes. A launcher runs a local cluster you can kill -9; a benchmark measures it.
